# يوني هوم

## فحص الاتصال عند التشغيل

`npm.cmd run dev` يشغّل nodemon. قبل تشغيل Next.js تُفحص MongoDB وصلاحيات القراءة والكتابة، وتُفحص R2 برفع ملف صغير إلى `.unihome-health/` وقراءته ثم حذفه. أي فشل يمنع بدء الخادم، وتعديل ملفات البيئة يعيد الفحص والتشغيل تلقائيًا. يبقى تحديث الواجهة من مسؤولية Next.js.

`npm.cmd start` يجري الفحوصات نفسها للإنتاج دون nodemon. للفحص وحده: `npm.cmd run check:connections`. عند `DEMO_MODE=true` يُعلن بوضوح أن الخدمات الخارجية لم تُفحص. لا تُعرض المفاتيح في رسائل الفحص. يجب أن يحتوي `R2_ACCOUNT_ID` على معرّف الحساب فقط. رمز الدولار الحرفي في ملفات البيئة يُكتب `\$` حتى لا يفسّره Next.js كمتغير بيئة.

تطبيق عربي لتنظيم فواتير سكن من ستة أشخاص. Next.js / React / TypeScript، مع MongoDB وCloudflare R2.

## التشغيل المحلي

يتطلب Node.js 22 أو أحدث. في PowerShell استخدم `npm.cmd` إذا كانت سياسة الجهاز تمنع `npm.ps1`.

```powershell
npm.cmd install
npm.cmd run dev
```

افتح http://localhost:3000. ملف `.env.local` الحالي يفعّل **وضعًا تجريبيًا محليًا** يحفظ الحسابات والملفات داخل `.data/`، ولا يتصل بـMongoDB أو R2. يمكن اختيار أحد الحسابات من شاشة الدخول التجريبية. لا توجد فواتير أو بيانات بنكية مصطنعة؛ يبدأ كل رصيد بصفر. هذا الوضع لعملية خادم واحدة فقط، وليس للاستضافة العامة.

## الربط الفعلي

عدّل `.env.local` أو متغيرات بيئة الاستضافة، ثم أعد تشغيل الخادم:

```dotenv
DEMO_MODE=false
APP_CURRENCY=TRY
APP_ORIGIN=https://home.example.com
MONGODB_URI=mongodb+srv://USER:PASSWORD@HOST/
MONGODB_DB=unihome
R2_ACCOUNT_ID=...
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
R2_BUCKET=unihome-private
```

استخدم حاوية R2 خاصة ومفتاحًا مقتصرًا على قراءة وكتابة كائناتها. تُرفع الملفات عبر الخادم فلا تحتاج إلى إعداد CORS للحاوية. الروابط تُصدر بعد فحص الجلسة وصلاحية الوصول وتنتهي بعد 60 ثانية. الإيصالات لا يراها إلا صاحبها والمشرف. الأنواع المقبولة PNG/JPEG/WebP وPDF للإيصالات، بحد أقصى 5 ميغابايت وفحص لتوقيع الملف. ضبط حد طلبات الوكيل العكسي إلى 6 ميغابايت مناسب لهذه الرفعات.

شغّل `npm.cmd run build` ثم `npm.cmd start` خلف HTTPS؛ كوكي الجلسة في الإنتاج Secure وHttpOnly. يسمح الخادم بالطلبات المغيّرة للبيانات من نفس مصدر الموقع فقط. عند وضع وكيل عكسي احتفظ باسم المضيف وبروتوكول HTTPS الصحيح. لا تعرّض `.data` أو مفاتيح البيئة للنشر العام. البيانات التجريبية لا تنتقل تلقائيًا إلى MongoDB.

## سلوك الحسابات

- الرصيد مجموع الطلبات «بانتظار الدفع» و«قيد المراجعة». لا ينخفض لمجرد إرسال التنبيه.
- يقسّم المشرف المبلغ بين أشخاص محددين. الحساب بالقروش الصحيحة وتوزيع الباقي على أول المشاركين يحفظ المجموع.
- تُحفظ بيانات المستفيد لحظة إنشاء الطلب؛ تحديث آيبانه لاحقًا لا يغير طلبًا قائمًا.
- المستخدم يحوّل خارج التطبيق ثم يرسل تنبيهًا. رفع الوصل اختياري. تأكيد المشرف يصفّر مبلغ الطلب، والرفض يعيده للدفع مع السبب.
- تعديل المبلغ متاح للطلب غير المدفوع. حذف الطلب يلغي أثره على الرصيد ويحفظه بالسجل. الطلبات المسددة لا تُحذف.
- تستخدم MongoDB مجموعات مستقلة للمستخدمين والمدفوعات والإشعارات والملفات والجلسات، مع transactions لحفظ التغييرات المترابطة. راجع [دليل قاعدة البيانات](DATABASE.md) للحذف وإعادة إنشاء الحسابات وتفاصيل الترحيل.
- الإشعارات داخل الموقع وتُحدّث كل 15 ثانية عندما تكون الصفحة ظاهرة؛ ليست SMS أو إشعارات دفع على الهاتف.
- تغيير كلمة المرور ينهي جلسات المستخدم الأخرى. هناك حد لمحاولات الدخول على الحساب (8 خلال 15 دقيقة). الجلسة صالحة 7 أيام.
- الصور والإيصالات المستبدلة تبقى في التخزين كسجل؛ يمكن إضافة سياسة تنظيف للملفات القديمة مستقبلًا.

## الفحوصات

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
```

اختبارات المنطق تغطي الصلاحيات، حالات الطلبات، حساب الرصيد، دقة التقسيم، الحسابات الأولية، وصحة المدخلات. لاختبار المتصفح ثبّت Chromium باستخدام `npx.cmd playwright install chromium`، ثم أوقف خادم التطوير المعتاد وشغّل خادم الاختبارات في نافذة:

```powershell
$env:DEMO_MODE='true'
$env:DEMO_DATA_DIR='e2e-' + [DateTimeOffset]::UtcNow.ToUnixTimeMilliseconds()
npm.cmd run dev -- --port 3001
```

في نافذة ثانية شغّل `node tests/e2e.mjs`. يُنشئ الاختبار طلبات ويغيّر كلمة مرور حساب اختباري، لذلك استخدم مجلد اختبار جديدًا لكل تشغيل. البيانات معزولة داخل `.data/<DEMO_DATA_DIR>`، والبيانات المحلية المعتادة داخل `.data/local`. تحفظ لقطات المتصفح داخل `test-results/`.

المراجع: [Next.js route handlers](https://nextjs.org/docs/app/api-reference/file-conventions/route)، [جلسات cookies](https://nextjs.org/docs/app/api-reference/functions/cookies)، [روابط R2 الموقعة](https://developers.cloudflare.com/r2/api/s3/presigned-urls/).
